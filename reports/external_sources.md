# External sources

with public sources, provided they're cited (see its "Data" section). Every
external figure pulled into this pipeline — Phase 3's financial baselines,
and any competitive-intelligence context used in later briefing notes —
gets logged here: entity, figure, value, source URL, retrieval date, and
the confidence flag carried alongside it in the data. Nothing goes into a
model input without a row here.
